# RFPilot


AI-powered Enterprise RAG & Solution Intelligence Platform.

RFPilot is an open-source AI application designed to analyse
business documents, extract requirements, retrieve relevant
information and generate evidence-backed responses.
Tech Stack
- Python
- FastAPI
- React
- Ollama
- Qwen3
- ChromaDB
- SQLite
Current Features
- PDF document upload
- Text extraction and chunking
- Local embedding generation
- Persistent vector storage
- Hybrid retrieval using BM25 and vector search
- LLM-powered document question answering
- Source references with page numbers
Project Status
Currently under active development.
Running Locally
Setup instructions will be expanded as development progresses.
